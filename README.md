Este é um projeto [Next.js](https://nextjs.org) iniciado com [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

> **MUITO IMPORTANTE:**
> * **Nunca façam push do `.env.local`** (o `.gitignore` já o bloqueia por defeito). Criem e mantenham um ficheiro `.env.example` limpo para a equipa saber de que variáveis precisa.
> * Trabalhem em **branches separadas por funcionalidade** (ex.: `git checkout -b feat/supabase-auth` ou `feat/home-filters`) e façam **Pull Requests** para a `main`.
